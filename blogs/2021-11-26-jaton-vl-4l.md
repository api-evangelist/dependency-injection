One of very few cards with S3 805i chipset that supports memory interleaving to improve performance. S3 86C805i-P VGA controller: Chrontel CH8391v RAMDAC. Drivers: Windows 3.1, S3 Flat Model Reference drivers VGA BIOS chip is soldered in onto the motherboard.
